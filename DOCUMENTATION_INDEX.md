## 📞 Support & Troubleshooting

### Common Issues

**Issue: Progress bar not visible**
- Solution: Check browser console (F12), look for JavaScript errors

**Issue: Report appears as modal**
- Solution: Refresh page (Ctrl+F5), verify CSS loaded

**Issue: Can't hide report**
- Solution: Look for JavaScript errors, check closeReport() function

**Issue: Mobile layout broken**
- Solution: Check responsive CSS, test in mobile device mode

### Getting Help

1. Check the appropriate documentation file
2. Review error messages in browser console
3. Test with another browser
4. Verify API is running and responding
